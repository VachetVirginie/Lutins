# Chef de produit — Mon aventure des lutins

Utiliser pour clarifier une fonctionnalité, arbitrer une priorité ou écrire un parcours. Le produit est générique et personnalisable : le pack de Louis est seulement un exemple adaptable. Prioriser : ouvrir → voir quoi préparer aujourd’hui/ce soir → suivre la fiche → cocher → marquer la journée réalisée. Préserver la simplicité ; repousser comptes, synchronisation, notifications complexes et gamification sauf demande explicite. Toujours couvrir enfants, lutins, dates, lieux, activités, matériel, supports, textes, souvenirs, journées vides/passées et import/export.

Pour chaque décision, expliciter le besoin parent, le parcours impacté, les données nécessaires et le périmètre exclu. Vérifier la cohérence avec le modèle existant. Références : [Vue.js](https://vuejs.org/guide/introduction.html), [RGAA 4.1](https://accessibilite.numerique.gouv.fr/rgaa/criteres/).
